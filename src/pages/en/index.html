From plugin to module in a club

The platform installs, clubs switch on.

  1. Reviewed and installed

    A plugin runs with access to the platform's data. So only Hubra's platform admins install plugins, after a review, in the plugin catalogue.

  2. Clubs switch modules on

    A plugin's modules show up for every club under Settings › Modules like built-in ones. Clubs install nothing and never upload code.

  3. Updates without a core release

    The platform rolls out a new plugin release without rolling out Hubra itself again. Every version is signed and carries its changes, and it can always go back to the previous version.
