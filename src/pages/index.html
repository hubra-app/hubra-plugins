So kommt ein Plugin in euren Verein

Wir prüfen, ihr schaltet ein.

  1. Geprüft und installiert

    Ein Plugin läuft mit Zugriff auf die Daten der Plattform. Darum installieren nur die Hubra-Plattform-Admins Plugins, nach einer Prüfung, im Plugin-Katalog.

  2. Euer Vorstand schaltet ein

    Unter Einstellungen › Module & Plugins schaltet ihr ein Plugin für euren Verein ein oder aus, wie jedes eingebaute Modul.

  3. Updates mit Signatur

    Jede Version ist signiert und hat ihre Änderungen dabei. Eine Hubra installiert nur, was mit einem vertrauten Schlüssel signiert ist, und kann auf die vorige Version zurück.
