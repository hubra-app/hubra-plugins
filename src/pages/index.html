Vom Plugin zum Modul im Verein

Die Plattform installiert, Vereine schalten ein.

  1. Geprüft und installiert

    Ein Plugin läuft mit Zugriff auf die Daten der Plattform. Darum installieren nur die Hubra-Plattform-Admins Plugins, nach einer Prüfung, im Plugin-Katalog.

  2. Vereine schalten Module ein

    Die Module eines Plugins erscheinen bei jedem Verein unter Einstellungen › Module wie eingebaute Module. Vereine installieren nichts und laden keinen Code hoch.

  3. Updates ohne Core-Release

    Ein neues Plugin-Release spielt die Plattform ein, ohne Hubra selbst neu auszurollen. Jede Version ist signiert und hat ihre Änderungen dabei, und es geht jederzeit auf die vorige Version zurück.
