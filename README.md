# Hubra official plugins

The signed plugin marketplace that every Hubra reads from
<https://plugins.hubra.club/index.json>. Each `<id>-<version>.zip` carries a
`SIGNATURE.json`, and `index.json` is signed too, with the official key
`Hubra.pub` that ships with Hubra.

Published by GitHub Actions from the plugin sources; don't edit by hand.
